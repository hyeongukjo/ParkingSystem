## 2. 프로젝트 주제

### Java 기반 2D 주차장 관리 시스템

Java Swing과 Java 2D(Graphics2D) 커스텀 렌더링을 활용하여 주차장의 모습을 위에서 내려다보는 탑다운(Top-down) 방식으로 표현하고, 차량의 입차와 출차 과정을 시각적으로 확인할 수 있는 주차장 관리 프로그램을 개발한다.

단순히 차량 정보를 입력하고 출력하는 프로그램이 아니라, 실제 주차장처럼 차량이 빈 주차 공간으로 이동하고 출차 시 화면에서 사라지는 기능을 구현하는 것이 목표이다.


## 3. 프로젝트 개발 목적

주차장에서 발생하는 차량 입차, 주차 공간 배정, 출차 및 요금 계산 과정을 하나의 프로그램으로 관리하고자 한다.

사용자는 차량번호를 입력하여 입차 또는 출차를 요청할 수 있으며, 주차장 화면을 통해 현재 주차 상태를 직관적으로 확인할 수 있다.

또한 객체지향 프로그래밍을 활용하여 차량 정보, 주차 공간, 요금 계산 등의 기능을 클래스로 분리하고, 프론트엔드와 백엔드를 분리해 개발하되 둘 사이는 **하나의 인터페이스로만 연결되는 구조**로 설계함으로써 모듈화와 협업 과정을 경험하는 것을 목표로 한다.


## 4. 주요 구현 기능

### 4.1. 차량 입차 기능

- 차량번호를 입력받아 입차를 등록한다.
- `Vehicle`을 부모 클래스로 하고 `Car`, `Motorcycle`, `Truck` 등 차종별 하위 클래스로 상속 구조를 설계한다.
- 동일한 차량번호가 이미 등록되어 있는지 확인한다.
- 빈 주차 공간을 검색하여 차량에 자동으로 배정한다.
- 주차장이 가득 찬 경우 입차할 수 없다는 메시지를 출력한다.
- 입차한 차량의 번호, 차종, 입차 시간, 배정된 공간을 저장한다.

### 4.2. 차량 출차 기능

- 차량번호를 입력받아 해당 차량을 검색한다.
- 등록되지 않은 차량은 출차할 수 없도록 처리한다.
- 입차 시간과 출차 시간을 이용하여 주차 요금을 계산한다.
- 출차가 완료되면 해당 주차 공간을 빈 상태로 변경한다.
- 출차 기록을 저장하고 계산된 요금을 화면에 표시한다.

### 4.3. 주차장 시각화 기능

- Java Swing을 이용하여 주차장 관리 화면을 구성한다.
- `JPanel`의 `paintComponent()`를 오버라이드하고 `Graphics2D`로 주차 공간, 도로, 자동차 등을 직접 렌더링한다.
- 약 n개의 주차 공간을 화면에 배치하고, 아스팔트 질감·주차선·화단·입구 차단봉 등 배경 요소로 현실감을 더한다.
- 승용차·전기차·트럭·이륜차 등 차종별로 서로 다른 도트(pixel-art) 스프라이트를 적용하여 주차 공간의 사용 여부를 그래픽으로 구분한다.
- 현재 주차 중인 차량 수와 빈 주차 공간의 수를 사이드바에 점유율 형태로 표시한다.

### 4.4. 자동차 이동 애니메이션

- 입차 시 자동차가 입구에서 배정된 주차 공간까지 이동하도록 구현한다.
- `javax.swing.Timer`를 이용해 일정 주기로 자동차의 화면 좌표를 갱신하며 부드러운 주행 애니메이션을 구현한다.
- 이동 경로는 점선으로, 도착할 주차 공간은 테두리 강조 효과로 표시하여 사용자가 흐름을 직관적으로 따라갈 수 있도록 한다.
- 출차 시 자동차가 주차 공간에서 출구 방향으로 이동하도록 구현한다.
- 출차 애니메이션이 끝나면 해당 자동차 그림을 화면에서 제거한다.

### 4.5. 주차 요금 계산

- 차량의 입차 시간과 출차 시간을 기준으로 이용 시간을 계산한다.
- 기본요금과 추가 시간에 따른 요금 계산 방식을 적용하며, 차종에 따라 요금 기준을 다르게 둘 수 있도록 설계한다.
- 요금 정책은 개발 과정에서 구체적으로 결정하고 별도 클래스로 관리한다.
- 계산된 주차 시간과 최종 요금을 출차 시 표시한다.

### 4.6. 차량 검색 및 주차 현황 조회

- 차량번호를 이용하여 현재 주차 중인 차량을 검색한다.
- 주차된 차량을 클릭하면 번호판, 입차 시각, 경과 시간, 예상 요금을 말풍선 형태로 보여주고, 이 화면에서 바로 출차 처리를 요청할 수 있도록 한다.
- 전체 주차 공간 수, 사용 중인 공간 수, 남은 공간 수를 표시한다.
- 최근 입출차 기록을 사이드바에서 함께 확인할 수 있도록 한다.
- 차량의 입차 및 출차에 따라 주차 현황을 갱신한다.

### 4.7. 주차 기록 관리

- 출차가 완료된 차량의 이용 기록을 저장한다.
- 차량번호, 입차 시간, 출차 시간, 주차 요금 등의 정보를 기록한다.
- 프로그램을 재실행한 후에도 기존 기록을 확인할 수 있도록 파일 저장 기능을 구현한다.


## 5. 기존 수업 및 과제와의 차별점

기존 수업과 과제에서는 주로 개별 클래스를 설계하거나 객체의 메서드를 호출하여 결과를 출력하는 방식으로 프로그램을 작성하였다.

이번 프로젝트에서는 단순한 차량 객체의 생성이나 이동 정보 출력을 넘어 다음과 같은 기능을 추가하고자 한다.

1. 여러 차량과 주차 공간을 동시에 관리하는 기능
2. 입차 및 출차에 따른 주차 상태 변경 기능
3. 주차 시간에 따른 요금 계산 기능
4. 차량번호 중복 확인 및 예외 처리 기능
5. Java Swing과 Graphics2D 커스텀 렌더링을 이용한 주차장 시각화 기능
6. `javax.swing.Timer` 기반으로 실제 자동차 이동을 표현하는 애니메이션 기능
7. 주차 기록을 저장하고 조회하는 기능
8. 프론트엔드와 백엔드를 인터페이스로 분리하여, 백엔드 완성 전에도 Mock 구현으로 화면 개발을 병행하는 협업 구조

이러한 기능을 통합하여 기존의 단순한 클래스 단위 실습보다 규모가 큰 프로그램을 구현하고자 한다.

## 7. 프론트엔드와 백엔드 연동 계획

프론트엔드와 백엔드는 하나의 공용 인터페이스(`ParkingService`)를 통해서만 연결되며, 서로의 내부 구현에 직접 의존하지 않도록 설계한다.

```java
public interface ParkingService {
    SlotInfo enter(String plate, VehicleType type) throws ParkingException; // 만차·중복 시 예외
    Receipt exit(String plate) throws ParkingException;                    // 요금 계산 포함
    List<SlotInfo> getSlots();                                             // 화면 갱신용
}
```

예를 들어 입차 버튼을 클릭하면 프론트엔드는 `service.enter(번호판, 차종)`을 호출하고, 백엔드는 차량번호 중복 여부와 빈 공간을 확인하여 주차 공간을 배정한 뒤 결과(`SlotInfo`)를 반환한다. 프론트엔드는 반환받은 주차 공간 번호를 기준으로 자동차를 해당 위치까지 이동시키는 애니메이션을 실행한다.

출차 과정에서도 `service.exit(번호판)` 호출을 통해 백엔드가 출차 처리와 요금 계산(`Receipt`)을 담당하고, 프론트엔드는 결과를 화면에 표시하며 자동차의 출차 애니메이션을 실행한다. 만차나 미등록 차량처럼 업무 규칙에 어긋나는 경우 백엔드는 `ParkingException`을 던지고, 프론트엔드는 이를 받아 팝업 등으로 사용자에게 안내한다.

이처럼 차량 객체(`Vehicle`)를 직접 주고받지 않고 `SlotInfo`/`Receipt` 같은 별도의 데이터로 결과만 전달함으로써, 프론트엔드가 백엔드의 내부 상태를 직접 변경할 수 없도록 캡슐화한다. 또한 백엔드가 완성되기 전에는 동일한 인터페이스를 구현한 Mock 객체로 프론트엔드 개발을 먼저 진행할 수 있어, 두 사람이 서로를 기다리지 않고 병렬로 개발할 수 있다.
